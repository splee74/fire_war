# 🔥 Fire War — 불꽃 대장장이

웹 브라우저에서 바로 즐기는 **대장간 경영 + 서바이버라이크 액션** 게임입니다.
대장간에서 무기를 벼리고, 차원의 균열로 출정해 몰려오는 괴물과 보스를 물리치세요.

설치할 것 없이 `index.html`을 브라우저로 열면 바로 플레이할 수 있어요.

## 게임 방법

### 🔨 대장간
- 모루를 클릭하거나 **스페이스바**를 눌러 무기를 만들어요 (일반 · 고급 · 희귀 · 영웅 · 전설).
- 무기를 팔아 골드를 벌고, 강화하고, 대장간 시설을 업그레이드해요.
- 무기를 최대 **3개 장착**하면 출정할 때 해당 무기로 시작해요. 등급이 높을수록 시작 레벨이, 강화할수록 피해량이 올라가요.
- 💠 마정석: +5 이상 강화가 실패했을 때 파괴를 막고, 정련 단조(희귀 이상 확정)에 써요.
- 🐉 용의 비늘: 용린 단조(영웅 이상 확정, 30% 전설)에 써요.

### ⚔️ 출정
- 이동: **WASD** / **방향키** / 화면 드래그 (모바일)
- 공격은 자동이에요. 레벨업할 때마다 무기나 장비 3개 중 하나를 골라요.
- 일시정지: **Esc** · 소리 켜기/끄기: **M**
- 5분과 10분에는 보스가, **15분에는 최종 보스**가 나타나요. 최종 보스를 쓰러뜨리면 승리!
- 출정에서 얻은 골드와 재료는 대장간으로 돌아가요.

## 구성

| 분류 | 내용 |
|---|---|
| 무기 8종 | 투척 단검, 회전 수리검, 화염 활, 관통 쇠뇌, 천둥 낙뢰, 서리 폭발, 차원 소용돌이, 초승달 베기 |
| 장비 6종 | 가죽 장화, 수호 방패, 자석, 행운의 클로버, 바람의 날개, 회복 물약 |
| 몬스터 9종 | 지그재그 유령, 화살 쏘는 해골 궁수, 분열하는 독 슬라임, 돌진 악마 등 |
| 보스 3종 | 화염룡 이그니스, 공허의 군주 녹스, 차원의 지배자 |

### 주인공 모델 바꾸기
애니메이션이 들어 있는 GLB 파일을 준비한 뒤, 아래 명령으로 `models/hero.js`를 다시 만들면 돼요.
```
node tools/make-hero.js 내모델.glb --list                     # 애니메이션 이름 보기
node tools/make-hero.js 내모델.glb Idle Run Attack Death Cheer   # 쓸 애니메이션만 남기기
```
애니메이션 이름은 `render3d.js`의 `HERO_ANIMS`에서 상태(대기·달리기·공격·사망·환호)와 연결해요.

## 기술
- HTML · CSS · JavaScript 파일 하나 (`index.html`), 외부 라이브러리 없음
- Canvas 2D 렌더링, 공간 분할 격자로 수백 마리 적 처리
- 효과음과 배경음악은 Web Audio API로 실시간 합성
- 진행 상황은 브라우저 `localStorage`에 저장
